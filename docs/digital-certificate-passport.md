# جواز الشهادات الرقمي

جواز الشهادات الرقمي صفحة مشاركة تجمع الشهادات التي سمح صاحبها بنشرها. وهو سجل إنجازات رقمي داخل منصة شهادتي، وليس جواز سفر حكوميًا أو ترخيصًا مهنيًا أو اعتمادًا خارجيًا.

## شروط الظهور
1. موافقة مستقلة من الخريج على نشر جواز الشهادات.
2. أن تكون الشهادة محددة للمشاركة عبر `visible_to_companies`.
3. وجود وقت موافقة مسجل للشهادة عبر `consent_given_at`.
4. أن تكون المؤسسة المصدرة معتمدة على المنصة.

## البيانات العامة
- اسم الخريج وبعض بيانات المؤهل العامة.
- اسم الدورة أو المؤهل، الجهة المصدرة، رقم الشهادة، تاريخ الإصدار، التخصص، المدة، والتقدير عند وجوده.
- حالة الشهادة، ورابط تحقق مستقل لكل شهادة.
- QR Code يفتح صفحة الجواز.

لا تعرض الصفحة الهاتف أو البريد أو الرقم القومي أو رابط ملف PDF أو أي مستند خاص. إذا سحب الخريج موافقته، تتوقف الصفحة العامة عن عرض الجواز.

## التحقق
QR Code يفتح صفحة الجواز، وكل شهادة ترتبط بصفحة التحقق الرسمية للمنصة باستخدام رقمها. قاعدة بيانات شهادتي هي مصدر حالة الشهادة، ولا يُعد شكل QR وحده دليلًا على صحتها.
