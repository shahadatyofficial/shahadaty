# المساعد الذكي للإدارة

## لوحة الإدارة المركزية
يحلل مؤشرات إجمالية عن المؤسسات والاشتراكات والتدريب والحضور والشهادات والخريجين والشركات والدعم.

## لوحة المؤسسة
يحلل بيانات المؤسسة أو الفرع وفق صلاحية `reports.view`. لا يستطيع مدير الفرع طلب بيانات فرع آخر، ولا تظهر له أرقام الاشتراك أو الشهادات المؤسسية العامة عند طلب تقرير فرع محدد.

## حماية البيانات
- المؤشرات التي تصل إلى نموذج الذكاء الاصطناعي مجمعة ولا تتضمن أسماء أو هواتف أو بريدًا أو أرقام هوية أو سجلات فردية.
- المساعد يقدم تحليلًا وتوصيات فقط؛ لا يغير بيانات النظام ولا يقبل قرارات حساسة نيابة عن الإدارة.
- التوصيات تحتاج مراجعة بشرية.
